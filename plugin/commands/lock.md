Lock the user's precinto-protected folders now.

Run exactly this command once with the Bash tool:

```
precinto lock
```

Then reply with one short sentence: that the folders are locked, or the error line the command printed. Do not run any other command and do not retry. Never run `precinto unlock`: only the user unlocks, in their own terminal.
