# Trademarks

This page explains how to use the name "precinto", and how this project uses the names of other products.

## The name "precinto"

"precinto" (written in lowercase) is the name of this project and of the software published from its repository. It tells people where a piece of software comes from, so we ask everyone to use it in a way that does not mislead.

The [Apache License 2.0](LICENSE) gives you broad rights over the code, but, as its section 6 says, it does not grant permission to use the project's name, except as reasonable and customary use requires to describe the origin of the work and to reproduce the [NOTICE](NOTICE) file. Within that frame:

**You may, without asking:**

- refer to precinto by name to say what your software works with or is built for ("works with precinto", "a precinto integration for X");
- write about precinto, teach it, review it, and link to it;
- redistribute unmodified copies of precinto under its own name, together with the license and the NOTICE file;
- say that your modified version is "based on precinto".

**Please do not:**

- distribute a modified version under the name "precinto", or a confusingly similar name; give it a different name and say clearly that it is based on precinto and is not the original;
- publish a plugin, package, harness integration or marketplace entry named "precinto", or one that looks like the official one, unless it comes from this project;
- use the name, or a confusingly similar one, for another product, service, company or domain in a way that suggests it is made, endorsed or certified by the precinto project;
- suggest that the precinto project endorses you, your product or your modifications.

If you are unsure whether a use is fine, ask the maintainers through the project's channels once the repository is published.
